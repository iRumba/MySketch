# Архитектура MySketch

## Компоненты

```
┌──────────────────┐    POST /dorisuy     ┌──────────────────┐    POST /v2/generate    ┌──────────────────┐
│  HTML5 Canvas   │  ──────────────────►  │  FastAPI Proxy   │  ──────────────────────► │  Fooocus API     │
│  (браузер)      │  ◄──────────────────  │  (сервер:8000)   │  ◄────────────────────── │  (Colab/GPU)     │
└──────────────────┘    image/png         └──────────────────┘    image (base64)        └──────────────────┘
```

## Поток данных

1. Пользователь рисует на canvas → toBlob() → FormData → POST
2. FastAPI читает PNG, конвертирует в base64
3. Отправляет в Fooocus: input_image + controlnet_image = рисунок пользователя
4. ControlNet (ImagePrompt) направляет генерацию, сохраняя форму наброска
5. Fooocus возвращает JSON с готовым изображением в base64
6. FastAPI возвращает image/png клиенту

## Технологии

| Компонент | Технология | Версия |
|-----------|-----------|--------|
| Клиент | HTML5 Canvas API | — |
| Сервер | Python FastAPI + uvicorn | 0.110+ |
| Генерация | Fooocus (SDXL + ControlNet) | latest |
| Транспорт | HTTP/REST | — |

## Требования к окружению

- **Python 3.10+** для прокси-сервера
- **Fooocus** — запускается в Colab (бесплатно)
- **GPU** — только для Colab (T4 или лучше)
