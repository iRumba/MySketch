# Требования MySketch

## Функциональные требования

| # | Требование | Статус |
|---|-----------|--------|
| 1 | Пользователь рисует чёрным карандашом на холсте 512×512 | ✅ |
| 2 | Кнопка «Очистить» сбрасывает холст | ✅ |
| 3 | Кнопка «Отменить» отменяет последнее действие | ✅ |
| 4 | Кнопка «Дорисуй» отправляет рисунок на сервер | ✅ |
| 5 | Сервер проксирует запрос в Fooocus API | ✅ |
| 6 | Результат отображается под холстом | ✅ |
| 7 | Поддержка touch-устройств | ✅ |

## Нефункциональные требования

- Время генерации: 10–30 секунд (зависит от Colab)
- Вес изображения: до 5 MB
- Поддержка современных браузеров
